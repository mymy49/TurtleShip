Detailed Description

Derived Color class that encodes RGBA values into a 16-bit Big-Endian 5-6-5 color code.

ColorRgb565BE is used by FrameBufferRgb565BE and BrushTftLcdRgb565BE to pre-calculate 16-bit byte-swapped (Big-Endian) color codes in mCode.

Stores the RGBA components and encodes them as a 16-bit Big-Endian 5-6-5 color code in mCode.

Parameters
[in]redRed component (0 ~ 255).
[in]greenGreen component (0 ~ 255).
[in]blueBlue component (0 ~ 255).
[in]alphaAlpha component (0 ~ 255, default 0xFF).
Author
Yoon-Ki Hong

Stores the 8-bit red, green, blue, and alpha values and packs them into a 2-byte array code[2] in Big-Endian byte order:

  • code[0] holds (mBlue & 0xF8) | (mGreen >> 5)
  • code[1] holds ((mGreen & 0xFC) << 3) | (mRed >> 3)

The resulting 16-bit word is stored in mCode.
