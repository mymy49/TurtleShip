Detailed Description

Interactive push-button widget with pre-rendered 3D beveled pushed/pulled states and event callbacks.

Button extends Object to provide a tactile push-button widget. To minimize rendering latency during touch interactions, Button maintains two internal off-screen frame buffers (mPushedFb and mPulledFb) in addition to its composite buffer (mFrameBuffer):

  • mPulledFb (Released state): Rendered with a raised 3-pixel 3D bevel highlight on the top/left edges, shadow on the bottom/right edges, and centered label text.
  • mPushedFb (Pressed state): Rendered with an inset 3-pixel 3D bevel shadow on the top/left edges, highlight on the bottom/right edges, and label text shifted by (+2, +2) pixels.

When a user presses or releases the button (handlerPush() / handlerUp()), paint() simply blits the pre-rendered mPushedFb or mPulledFb bitmap and invokes the registered callback (mPushHandler or mUpHandler).

Note
Pending future update: Recent framework updates for GUI widgets have not yet been applied to Button. The existing implementation is intentionally preserved without modification pending upcoming revisions.
