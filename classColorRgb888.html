Detailed Description

Derived Color class representing 24-bit RGB888 / 32-bit ARGB8888 colors.

Provides a specialized Color interface for 24-bit RGB888 surfaces. Note that the base Color class already encodes 32-bit ARGB8888 (0xAARRGGBB) by default.
