Detailed Description

GUI widget that renders a centered single-line UTF-8 text string on a solid background.

Label extends Object to display a text caption (mText) horizontally and vertically centered (Brush::ALIGN_CENTER_MID) inside its FrameBufferRgb565LE canvas (mFrameBuffer). Whenever the text string, font color, or background color is updated, Label marks itself dirty via touch() so its parent Container or Frame repaints it on the next update cycle.
