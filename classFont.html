Detailed Description

Abstract base class providing UTF-8 character decoding, glyph metric lookup, and text width/height calculation.

Font defines the interface between Brush text rendering methods (Brush::drawChar(), Brush::drawString(), Brush::calculateStringArea()) and concrete font storage backends such as CodeFont (ROM/Flash C-array fonts generated by the yss font tool).

Each glyph is described by a packed fontInfo_t structure containing its 32-bit packed UTF-8 code, pixel dimensions (width, height), bearing offsets (xpos, ypos), and a pointer to the 4-bit-per-pixel anti-aliased alpha bitmap (data).

Users can optionally override the advance width of space characters (setSpaceWidth()), period/dot characters (setDotWidth()), or enforce a minimum monospace-like character advance width (setCharWidth()).

Example Usage in User Application

#include <bsp.h>
#include <font/Ubuntu_14_B.h>
#include <font/Ubuntu_20_B.h>
void renderTitleText(void)
{
brush.setSize(240, 20);
brush.setBackgroundColor({0xFF, 0xFF, 0xFF});
brush.setBrushColor({0x00, 0x00, 0x00});
brush.setFont(Font_Ubuntu_14_B);
brush.clear();
brush.drawString(Brush::ALIGN_CENTER_MID, "NuMaker-M251KG V1.1");
lcd.drawBitmap({0, 100}, brush.getBitmap());
}

◆ getStringWidth()

uint16_t Font::getStringWidth ( const char * str)

Calculates the total horizontal width in pixels of a null-terminated UTF-8 string.

Parameters
[in]strNull-terminated UTF-8 string to measure.
Returns
Total string width in pixels.
Author
Yoon-Ki Hong

Decodes every UTF-8 character in str via getUtf8() and sums the horizontal advance widths of all characters.

  • When mCharWidth is non-zero, each character advances by at least mCharWidth pixels (or its actual glyph width if wider).
  • When mCharWidth is zero, proportional glyph widths (fontInfo->width + (int8_t)fontInfo->xpos, plus 1 pixel if xpos == 0) are summed, using mSpaceWidth (or 4) for spaces and mDotWidth (or 4) for periods.
    See also
    Font::getUtf8(), Font::getFontInfo()

◆ getUtf8()

uint32_t Font::getUtf8 ( const char ** src)

Decodes the next UTF-8 character from *src and advances the *src pointer past the decoded bytes.

Parameters
[in,out]srcPointer to a C-string pointer; advanced by 1, 2, or 3 bytes depending on the UTF-8 sequence length.
Returns
Packed 32-bit UTF-8 code (1-byte ASCII in [7:0], 2-byte sequence in [15:0], 3-byte sequence in [23:0]), or 0 if an invalid byte (0x80 ~ 0xBF) is encountered.
Author
Yoon-Ki Hong

Inspects the leading byte at *(*src) to determine the UTF-8 sequence length and packs the raw UTF-8 bytes into a 32-bit unsigned integer:

  • 3-byte sequence (>= 0xE0): Packs 3 consecutive bytes into bits [23:16], [15:8], and [7:0].
  • 2-byte sequence (>= 0xC0): Packs 2 consecutive bytes into bits [15:8] and [7:0].
  • 1-byte ASCII (< 0x80): Returns the single byte in bits [7:0].
  • Continuation/invalid byte (0x80 ~ 0xBF): Advances *src by 1 byte and returns 0.
