Detailed Description

Concrete Font implementation backed by C-array glyph tables stored in program memory (Flash/ROM).

CodeFont wraps a codeFontInfo_t table generated by the yss OS font generator tool (e.g. Font_Ubuntu_14_B, Font_Ubuntu_20_B). To accelerate glyph lookup without requiring a large flat array across the entire Unicode range, characters are partitioned into NUM_OF_CHAR_GROUP (8) buckets indexed by the lowest 3 bits of the UTF-8 code (ch & 0x07).

Example Usage in User Application

#include <bsp.h>
#include <font/Ubuntu_14_B.h>
#include <font/Ubuntu_20_B.h>
// In Ubuntu_14_B.h:
// extern CodeFont Font_Ubuntu_14_B;
void showCalibrationScreen(void)
{
lcd.lock();
brush.setSize(210, 23);
brush.setFont(Font_Ubuntu_20_B);
brush.setBackgroundColor({0x00, 0x00, 0x00});
brush.setBrushColor({0xFF, 0xFF, 0x30});
brush.clear();
brush.drawString(Brush::ALIGN_CENTER_MID, "[Touch Calibration]");
lcd.drawBitmap({15, 100}, brush.getBitmap());
lcd.unlock();
}

Searches the appropriate hash group in mInfo for the glyph matching ch.

Parameters
[in]chPacked UTF-8 character code.
Returns
Pointer to the matching Font::fontInfo_t entry, or nullptr (0) if not found.
Author
Yoon-Ki Hong

Selects the glyph group using the lower 3 bits of ch (group = ch & 0x7), then performs a linear search over the mInfo->numOfChar[group] entries in mInfo->fontInfo[group] to find an entry whose utf8Code equals ch. Returns &info[i] on match, or 0 (nullptr) if not found.
