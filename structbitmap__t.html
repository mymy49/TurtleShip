Detailed Description

Standard bitmap descriptor used by Brush, FrameBuffer, and TftLcdDriver drawing APIs.

Holds the dimensions (width, height), pixel encoding (type), and a pointer (data) to the contiguous pixel array. Bitmap assets generated by yssBmpMaker or exported from a FrameBuffer via FrameBuffer::getBitmap() use this structure.

Example Usage in User Application

#include <TurtleShipTypes.h>
extern const bitmap_t NuvotonLogo;
void drawLogo(void)
{
lcd.lock();
lcd.drawBitmap({20, 30}, NuvotonLogo);
lcd.unlock();
}
