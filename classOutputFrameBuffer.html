Detailed Description

Adapter class bridging a top-level Frame and the system display output frame buffer.

Holds a reference to the active Frame (mFrame) and the underlying SystemOutputFrameBuffer (mFrameBuffer) and provides virtual update() hooks for partial and full-screen refreshes.
