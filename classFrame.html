Detailed Description

Root full-screen GUI window that composites child Object widgets and flushes updates to the system display.

Frame extends Container to represent a top-level screen or page fixed at (0, 0) with the dimensions of the system TFT LCD (system::getSystemTftLcdSize()).

  • Its position and size are locked (mResizeAble = false, and setPosition() is a no-op).
  • Whenever child widgets are added or invalidated via update(), Frame composites the dirty region into mFrameBuffer and flushes the updated bitmap to the display via system::drawBitmap().
  • It can be registered as the active system frame via setAsSystemFrame() and linked with a PointerDevice for automatic touch event routing and cleanup on destruction.
Note
Pending future update: Recent architectural updates (such as migration to Area) have not yet been applied to Frame. Legacy Rectangular dirty-region management is intentionally preserved pending upcoming refactoring.
