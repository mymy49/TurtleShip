Detailed Description

BrushTftLcdRgb565 specialization using Little-Endian 16-bit RGB565 colors (ColorRgb565LE).

BrushTftLcdRgb565LE manages foreground (mBrushColor), background (mBgColor), and font (mFontColor) colors in Little-Endian RGB565 format. It also holds a pointer (mFb) to an external FrameBufferRgb565LE instance registered via setFrameBuffer(), allowing SPI/parallel TFT LCD drivers (such as ST7789V_spi_with_Brush_RGB565 and Touch_LCD_Shield_for_Arduino_2_8_inch) to use the shared buffer for fast block fills (fillRectBase(), clear()).

Example Usage in User Application

#include <bsp.h>
Touch_LCD_Shield_for_Arduino_2_8_inch lcd; // Inherits BrushTftLcdRgb565LE
FrameBufferRgb565LE brush;
void initLcd(void)
{
brush.malloc(5000);
lcd.initialize(lcdConfig);
lcd.setFrameBuffer(brush);
lcd.setBackgroundColor({0xFF, 0xFF, 0xFF});
lcd.clear();
}
