Detailed Description

Abstract base class for TFT LCD drivers controllable over a communication bus (SPI, I2C, parallel, etc.).

Any TFT LCD driver that configures and updates a display panel over a communication channel must inherit from TftLcdDriver and implement its pure virtual interface (getLcdSize() and drawBitmapBase()).

Because TftLcdDriver inherits from Mutex, multi-threaded user applications can safely serialize concurrent screen updates by calling lcd.lock() and lcd.unlock().

Example Usage in User Application

#include <bsp.h>
#include "../bmp/drawing.h"
void pageDisplayMain(void*)
{
lcd.lock();
lcd.setBackgroundColor({0x00, 0x00, 0x00});
lcd.clear();
lcd.drawBitmap({20, 20}, drawing);
lcd.unlock();
}
