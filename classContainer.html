Detailed Description

Composite Object capable of holding, painting, updating, and routing touch events to child Object widgets.

Container maintains a dynamically grown array (mObjArr) of child Object* pointers and its own FrameBufferRgb565LE canvas (mFrameBuffer).

  • Rendering & Partial Updates: When update(rect) or update(before, current) is called, Container clears the dirty region(s) in mFrameBuffer, calls paint() on any child whose isModified() flag is set, and blits each visible child's bitmap clipped to the dirty region(s). It then propagates the translated dirty region up to its own parent container (mParent).
  • Hit Testing & Event Routing: handlerPush() and handlerDrag() iterate through mObjArr in reverse Z-order (top-most child first), test whether the touch position falls inside a visible child's bounding box, translate the coordinate into child-local space, and forward the event.
Note
Pending future update: Recent architectural updates to Object (such as migration to Area) have not yet been synchronized into Container. Legacy Rectangular signatures are intentionally preserved pending future updates.
