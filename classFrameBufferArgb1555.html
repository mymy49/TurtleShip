Detailed Description

Off-screen frame buffer class for 16-bit ARGB1555 (1-bit Alpha, 5-bit Red, 5-bit Green, 5-bit Blue) bitmaps.

Provides a 2-bytes-per-pixel off-screen canvas that exports BITMAP_TYPE_ARGB1555 bitmaps via getBitmap().

Note
Currently retained as a legacy/experimental class; FrameBufferRgb565LE is the primary frame buffer used in active builds.
