Detailed Description

Concrete 16-bit RGB565 FrameBuffer storing pixels in Little-Endian byte order.

FrameBufferRgb565LE is the standard off-screen drawing canvas used across yss OS applications and display widgets (ValueDisplay, ProgressDisplay, RpmBarDisplay, Button, Label, etc.) on Little-Endian ARM Cortex-M microcontrollers.

It encodes foreground and background colors via ColorRgb565LE and implements fast 16-bit RGB565 alpha blending in blendDot() for anti-aliased font rendering (Brush::drawString()) and custom graphics.

Example Usage in User Application

#include <bsp.h>
#include <font/Ubuntu_14_B.h>
#include <font/Ubuntu_20_B.h>
FrameBufferRgb565LE brush;
void drawCalibrationPoint(void)
{
lcd.lock();
// Resize off-screen canvas to 35x35 pixels, clear, and draw concentric circles
brush.setSize(35, 35);
brush.setBackgroundColor({0x00, 0x00, 0x00});
brush.clear();
brush.setBrushColor(0x80, 0x80, 0x80);
brush.fillCircle({5, 5}, 16);
brush.setBrushColor(0xFF, 0x30, 0x30);
brush.fillCircle({5, 5}, 5);
// Transfer the off-screen bitmap to the top-left corner of the LCD
lcd.drawBitmap({0, 0}, brush.getBitmap());
lcd.unlock();
}

void FrameBufferRgb565LE::blendDot ( int16_t x,
int16_t y,
uint8_t alpha )
overridevirtual

Alpha-blends the current brush color onto the Little-Endian RGB565 pixel at (x, y).

Parameters
[in]xX coordinate of the pixel (0 ~ width - 1).
[in]yY coordinate of the pixel (0 ~ height - 1).
[in]alphaBlending weight (0 ~ 255; values < 16 are ignored as transparent).
Author
Yoon-Ki Hong

Alpha-blends mBrushColorCode onto the existing Little-Endian RGB565 pixel at (x, y).

  1. Returns early if alpha < 16 (nearly transparent) or if (x, y) lies outside [0, width - 1] / [0, height - 1].
  2. Reads the 16-bit pixel blend = des[width * y + x].
  3. Unpacks 5-bit Red, 6-bit Green, and 5-bit Blue from both blend and mBrushColorCode into 8-bit fixed-point values and linearly interpolates each channel by alpha: $C_{\text{out}} = \lfloor((C_{\text{brush}} - C_{\text{des}}) \times \text{alpha}) / 256\rfloor + C_{\text{des}}$.
  4. Packs the blended channels back into 16-bit RGB565 (((r << 8) & 0xF800) | ((g << 3) & 0x07E0) | ((b >> 3) & 0x001F)) and stores the result into des[width * y + x].

    Brush::drawChar()
