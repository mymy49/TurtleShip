Detailed Description

Abstract base class providing generic 2D drawing primitives on a pixel canvas.

Brush implements device-independent 2D graphics algorithms—including straight lines, outlined and filled circles, triangles, rectangles, quadrangles, anti-aliased UTF-8 text rendering, and bitmap clipping helpers—on top of a small set of pure virtual pixel-level operations (drawDot(), blendDot(), fillDotArray(), drawBitmapBase(), getCanvasSize(), getPixelCapacity()).

Concrete drawing surfaces such as off-screen frame buffers (e.g. FrameBufferRgb565LE, FrameBufferRgb565BE) or direct TFT LCD drivers (e.g. BrushTftLcdRgb565LE, Touch_LCD_Shield_for_Arduino_2_8_inch) derive from Brush and implement the pixel-format or hardware-specific operations.

Text strings are rendered using a Font (such as CodeFont) registered through setFont(), with 4-bit per-pixel alpha blending handled via blendDot().

Example Usage in User Application

#include <bsp.h>
#include <font/Ubuntu_20_B.h>
void drawCloseButton(Area area)
{
lcd.lock();
// Off-screen rendering on a FrameBufferRgb565LE (which inherits Brush)
brush.setSize(area);
brush.setBackgroundColor(0x80, 0x80, 0x80);
brush.clear();
brush.setBrushColor(0xA0, 0xA0, 0xA0);
brush.fillRectangular({3, 3, 24, 34});
brush.setFont(Font_Ubuntu_20_B);
brush.setBrushColor(0x00, 0x00, 0x00);
brush.drawString(Brush::ALIGN_CENTER_MID, "X");
// Blit the rendered off-screen buffer onto the LCD (which also inherits Brush)
lcd.drawBitmap(area.getPosition(), brush.getBitmap());
// Direct line drawing on the LCD surface
lcd.setBrushColor({0xFF, 0x00, 0x00});
lcd.drawLine({10, 10}, {100, 80});
lcd.unlock();
}

◆ drawChar()

uint8_t Brush::drawChar ( Position pos,
uint32_t utf8 )

Renders a single UTF-8 character at the specified position using the current font and brush color.

Parameters
[in]posTop-left coordinate of the character cell on the canvas.
[in]utf8Packed UTF-8 character code (as returned by Font::getUtf8()).
Returns
Horizontal advance width in pixels to the next character position (0 if no font or glyph is available).
Author
Yoon-Ki Hong
Precondition
A valid Font must be attached via setFont().

Renders a single anti-aliased glyph from mFont onto the canvas using blendDot().

  1. Returns 0 if no font is set, or returns the space advance width if utf8 == ' '.
  2. Looks up Font::fontInfo_t for utf8. Each byte in fontInfo->data packs two 4-bit alpha nibbles (even pixel index in the low nibble, odd pixel index in the high nibble), padded to an even row width.
  3. Applies the glyph bearing offsets (xpos, ypos), ensuring at least 1 pixel of leading horizontal offset if xpos == 0, and clips the glyph rectangle to the canvas bounds.
  4. Iterates through the visible pixels of the glyph, expanding each 4-bit alpha value to 8 bits and blending it onto the canvas via blendDot().
  5. Returns the horizontal advance width to the next character cell.
    See also
    Brush::blendDot(), Font::getFontInfo()

Draws the perimeter of a circle centered at pos with the given radius using 8-way octant/quadrant symmetry.

Iterates x from 0 to radius - 1, calculates the corresponding vertical offset $y_p = \lfloor\sqrt{r^2 - x^2} + 0.5\rfloor$, and plots 8 symmetric points around (px, py) using drawDot().

◆ fillCircle()

void Brush::fillCircle ( Position pos,
uint16_t radius )

Draws a filled circle using the current brush color.

Parameters
[in]p1Center coordinate of the circle.
[in]rRadius of the circle in pixels.
Author
Yoon-Ki Hong
Warning
Nothing is drawn if the radius r is less than 3 pixels.

Renders a solid filled circle centered at pos with the given radius using horizontal scanline spans.

For each vertical offset i from 0 to radius - 1:

  1. Computes the half-chord length $\sqrt{r^2 - (i + 1)^2}$ using pow(..., 0.5f).
  2. Determines the left and right X bounds (sx, ex) around px and clamps them to [0, width - 1].
  3. Fills the lower scanline at y = py + i + 1 and the upper symmetric scanline at y = py - i via fillDotArray() if they lie within [0, height - 1].
    See also
    Brush::drawCircle(), Brush::fillDotArray()

Fills the interior of a triangle defined by three vertices with the current brush color.

Parameters
[in]p1First vertex coordinate.
[in]p2Second vertex coordinate.
[in]p3Third vertex coordinate.
Author
Yoon-Ki Hong

Rasterizes a filled triangle by sorting the three vertices and scanning horizontal spans.

  1. Sorts the vertices so that p1 is at the top (minimum Y) and orders p2, p3 horizontally.
  2. Rasterizes the upper sub-triangle from p1.y down to $\min(p2.y, p3.y)$ by computing the left and right edge slopes (slopeL, slopeR) and filling each scanline span via fillDotArray().
  3. If p2.y != p3.y, reorders the remaining vertices so p3 is the bottom-most vertex and rasterizes the lower sub-triangle from $\max(p1.y, p2.y)$ down to p3.y.
    See also
    Brush::drawTriangle(), Brush::fillDotArray()
