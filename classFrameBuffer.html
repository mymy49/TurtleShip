Detailed Description

Heap-allocated off-screen pixel buffer that can be drawn onto through the Brush interface.

FrameBuffer manages a contiguous block of RAM allocated once via malloc(maxPixelPoints) for a given maximum pixel capacity. Afterward, the logical canvas dimensions (mSize) can be resized dynamically at zero allocation cost via setSize() as long as width * height <= mMaxPixelCount.

Concrete subclasses (FrameBufferRgb565LE, FrameBufferRgb565BE, FrameBufferArgb1555, etc.) define the pixel format, bytes per pixel (getPixelCapacity()), pixel plotting (drawDot(), blendDot()), and export a bitmap_t descriptor via getBitmap() that can be blitted directly to a TftLcdDriver or parent Brush to prevent screen flickering.

Note
Memory is allocated from the L-heap (lmalloc / lfree) when YSS_L_HEAP_USE is enabled, or from the H-heap (hmalloc / hfree) otherwise.

Example Usage in User Application

#include <bsp.h>
#include <font/Ubuntu_14_B.h>
FrameBufferRgb565LE brush;
void initAndDrawBanner(void)
{
// Allocate buffer once for up to 5000 pixels (10,000 bytes in RGB565)
brush.malloc(5000);
// Dynamically resize the logical canvas within the 5000-pixel budget (240 * 20 = 4800 <= 5000)
brush.setSize(240, 20);
brush.setBackgroundColor({0xFF, 0xFF, 0xFF});
brush.setBrushColor({0x00, 0x00, 0x00});
brush.setFont(Font_Ubuntu_14_B);
brush.clear();
brush.drawString(Brush::ALIGN_CENTER_MID, "Powered by yss OS");
lcd.drawBitmap({0, 280}, brush.getBitmap());
}

◆ malloc()

void FrameBuffer::malloc ( uint32_t maxPixelPoints)

Allocates (or reallocates) the underlying heap buffer for maxPixelPoints pixels.

Parameters
[in]maxPixelPointsMaximum number of pixels the frame buffer must hold.
Author
Yoon-Ki Hong
Note
Any previously allocated buffer is freed first. The total byte allocation is maxPixelPoints * getPixelCapacity().
Postcondition
On success, mFrameBuffer points to the allocated block, mMaxPixelCount equals maxPixelPoints, and mMallocFlag is true. On failure, mFrameBuffer is nullptr and mMallocFlag is false.

Allocates a pixel buffer capable of holding maxPixelPoints pixels.

  1. Queries bytes-per-pixel via getPixelCapacity().
  2. Frees any previously allocated buffer if mMallocFlag is true.
  3. Allocates maxPixelPoints * getPixelCapacity() bytes from the L-heap (lmalloc) or H-heap (hmalloc).
  4. Updates mMaxPixelCount and mMallocFlag according to whether the allocation succeeded.
