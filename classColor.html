Detailed Description

RGBA color container with a cached pixel-format-specific hardware color code.

Color stores 8-bit red, green, blue, and alpha components (0 ~ 255) along with a pre-computed 32-bit color code (mCode).

The base Color class encodes mCode in 32-bit ARGB8888 format (0xAARRGGBB). Derived classes (ColorRgb565LE, ColorRgb565BE, ColorBgr565LE, ColorBgr565BE) override setColorBase() to compute 16-bit packed color codes tailored to the byte order and channel order of specific framebuffers and TFT LCD controllers.

Example Usage in User Application

#include <bsp.h>
static Color gBasicBorderColor = {0x80, 0x80, 0x80};
static Color gSelectedBorderColor = {0xFF, 0x00, 0x00};
void drawPaletteBox(Area area, Color bdColor, Color fillColor)
{
brush.setBackgroundColor(bdColor);
brush.setBrushColor(fillColor);
brush.clear();
brush.fillRectangular({2, 2, 26, 14});
lcd.drawBitmap(area.getPosition(), brush.getBitmap());
}
