Detailed Description

BrushTftLcdRgb565 specialization using Big-Endian 16-bit RGB565 colors (ColorRgb565BE).

Manages foreground (mBrushColor), background (mBgColor), and font (mFontColor) colors in Big-Endian RGB565 format and optionally holds a pointer to an auxiliary FrameBufferRgb565BE (mFb) used by LCD drivers to batch pixel transfers (such as solid fills) over SPI/bus interfaces.
