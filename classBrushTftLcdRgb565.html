Detailed Description

Base Brush adapter for TFT LCD drivers operating in 16-bit RGB565 pixel format.

BrushTftLcdRgb565 specializes Brush for 2-bytes-per-pixel (16-bit RGB565) TFT LCD devices. Endian-specific subclasses (BrushTftLcdRgb565LE and BrushTftLcdRgb565BE) extend this class to manage foreground/background Color encoding and optional working FrameBuffer association, while concrete LCD controller drivers (such as ST7789V_spi_with_Brush_RGB565 and Touch_LCD_Shield_for_Arduino_2_8_inch) implement the hardware pixel/window transfer methods.

Note
Concrete TFT LCD drivers typically override fillRectBase() directly to stream pixels over SPI/8080 bus.

No-op default implementation of fillDotArray() because a direct TFT LCD brush does not own a full-screen RAM frame buffer; hardware LCD subclasses override fillRectBase() to push pixel runs directly to the display controller window.
