Detailed Description

Utility class that computes clipped source/destination areas and pixel buffer offsets when drawing a bitmap.

When blitting a bitmap (bitmapSrcArea) into a specific clipping region (canvasDesArea) of a canvas of size canvasSize, parts of the destination region or the bitmap itself may fall outside the valid canvas bounds or outside the clipping region.

BitmapDrawingCalculator performs 2D intersection and clipping between:

  1. The full canvas bounds (0, 0 to canvasSize),
  2. The target clipping rectangle on the canvas (canvasDesArea), and
  3. The bitmap rectangle placed on the canvas (bitmapSrcArea).

After calling calculate(), callers can retrieve the trimmed dimensions, clipped areas, and linear pixel offsets into both the source bitmap data array and the destination canvas framebuffer.

Example Usage

Area bitmapArea = {bitmapPos, {bitmap.width, bitmap.height}};
BitmapDrawingCalculator bdc(canvasSize, canvasDesArea, bitmapArea);
if (bdc.calculate() == false)
return; // Bitmap does not intersect the visible destination area
uint16_t bwidth = bdc.getTrimedBitmapWidth();
uint16_t bheight = bdc.getTrimedBitmapHeight();
uint16_t *des = &frameBuffer[bdc.getCanvasDesFrameBufferOffset()];
uint16_t *src = &bitmapData[bdc.getBitmapSrcFrameBufferOffset()];

bool BitmapDrawingCalculator::calculate ( void )

Calculates the clipped source and destination rectangles and linear pixel offsets.

Returns
true if the bitmap and destination clipping area overlap within the canvas; false if nothing is visible.
Author
Yoon-Ki Hong
Postcondition
On returning true, trimmed areas and buffer offsets can be queried through the getter methods.

Computes the intersection between the canvas bounds, mCanvasDesArea, and mBitmapSrcArea.

The algorithm proceeds in four main stages:

  1. Early rejection: Returns false if the destination area starts beyond the canvas dimensions or if the bitmap rectangle and destination clipping rectangle do not overlap at all.
  2. Canvas boundary clamping: Clamps mTrimedCanvasDesArea so that negative X/Y coordinates are shifted to 0 and right/bottom edges exceeding mCanvasSize are reduced to fit within the canvas.
  3. Horizontal intersection (X-axis):
    • If the bitmap starts to the left of the destination area (bx < cax), advances the source pixel offset (mSrcFrameBufferOffset) by cax - bx and reduces the trimmed bitmap width.
    • Otherwise, sets the relative X coordinate of mTrimedBitmapSrcArea and advances the destination buffer offset (mDesFrameBufferOffset) by bx.
    • Clips the right edge of whichever area extends further to the right.
  4. Vertical intersection (Y-axis):
    • If the bitmap starts above the destination area (by < cay), advances mSrcFrameBufferOffset by (cay - by) * baw (skipping full bitmap rows) and reduces the trimmed bitmap height.
    • Otherwise, sets the relative Y coordinate of mTrimedBitmapSrcArea and advances mDesFrameBufferOffset by cw * by (skipping full canvas rows).
    • Clips the bottom edge of whichever area extends further downward.
