Detailed Description

Abstract base class representing a positionable, sizable, and touch-interactive GUI widget.

Object forms the root of the retained-mode widget hierarchy in TurtleShip (Container, Frame, Button, Label, etc.). Each Object maintains:

  • Its position (mPos) relative to its parent Container (mParent),
  • Visibility (mVisibleFlag), resizeability (mResizeAble), and dirty state (mModifiedFlag),
  • Touch/pointer event callbacks (handlerPush(), handlerDrag(), handlerUp()),
  • Partial invalidation propagation (update()) up the parent container hierarchy.

Derived widgets implement paint() to draw their visual representation into their internal FrameBuffer and call touch() whenever their visual properties change so the parent Container repaints them on the next update().
