Detailed Description

Derived Color class that encodes RGBA values into a 16-bit BGR565 Big-Endian color code.

ColorBgr565BE overrides setColorBase() to convert 8-bit RGB channels into a 16-bit byte-swapped (Big-Endian) 5-6-5 code stored in mCode.

Stores the 8-bit red, green, blue, and alpha values and packs the top 5 bits of red, top 6 bits of green, and top 5 bits of blue into a 2-byte array code[2] in Big-Endian byte order:

  • code[0] holds (mRed & 0xF8) | (mGreen >> 5)
  • code[1] holds ((mGreen & 0xFC) << 3) | (mBlue >> 3)

The resulting 16-bit word is stored in mCode.
